# Ride at Dawn — rideatdawn.gg

Website for the Ride at Dawn Old School RuneScape clan. Hosted on Netlify; every push to `main` goes live automatically.

- `index.html` — the whole site (live stats from Wise Old Man group 16463, drops from TempleOSRS group 3818)
- `_redirects` — Netlify proxy so the site can load TempleOSRS data
- `logo.jpg`, `logo-sm.jpg`, `ranks/` — images
